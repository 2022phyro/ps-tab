Component Specification • Core UI System v2.0.0 (Standard Tactile)

The Kwuo Button System

Standard, ergonomic geometry paired with a uniquely tactile oratorical personality. Direct harmony with Kwuo’s headers and footers, featuring rich warm shadows, responsive 1px mechanical press transitions, and high-contrast accessible tokens.

02 • Variant Hierarchy

Intent-Driven Button Variants

Standardized visual weight mapped to clear transactional priorities across tournament workflows.

1. Full Solid (Primary) Dominant

Deep Mahogany with warm bronze hover. For primary hero conversions, round submissions, and irreversible confirmations.

2. Alternate Filled Tactile Warm

Warm Sand surface with dark mahogany typography. High-prominence secondary action with tactile soft contrast.

{{ ui.button("Review Scorecard", variant="alternate", size="md", icon="ph-bold ph-pencil-simple") }}
Class: kwuo-btn-alternate
3. Full Outlined Crisp Frame

Transparent canvas with a distinct 1.5px solid border. Perfectly balances beside a Full Solid primary CTA.

{{ ui.button("Explore Workflows", variant="outline", size="md", icon="ph-bold ph-caret-down", icon_pos="right") }}
Class: kwuo-btn-outline
4. Surface Outlined Neutral

Surface card background with subtle parchment border. Harmonized with footer's Open Source and navigation controls.

{{ ui.button("Download CSV", variant="secondary", size="md", icon="ph-bold ph-download-simple") }}
Class: kwuo-btn-secondary
5. Ghost / Editorial Borderless

Zero border with warm hover wash. Ideal for low-emphasis utility actions, cancel options, and inline link pairs.

{{ ui.button("Cancel Changes", variant="ghost", size="md") }}
Class: kwuo-btn-ghost
6. Destructive (Danger) Warning

Solid and outlined crimson. Reserved for deleting tournaments, revoking signed ballots, and reset actions.

{{ ui.button("Delete Round", variant="danger", size="sm", icon="ph-bold ph-trash") }} {{ ui.button("Revoke", variant="danger-outline", size="sm") }}
Classes: kwuo-btn-danger & kwuo-btn-danger-outline
